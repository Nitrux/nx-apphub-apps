# Wofi

## Summary

A launcher and menu for wlroots-based Wayland compositors

## Description

Wofi is a fast application launcher and menu program for Wayland compositors. It supports launching desktop applications, running commands, and dmenu-compatible input, with appearance controlled through CSS.
