# kitty

## Summary

Fast, feature-rich, GPU-based terminal emulator

## Description

Kitty is a fast, GPU-based terminal emulator with support for modern terminal features such as graphics, Unicode, true color, OpenType ligatures, mouse protocol, and focus tracking. It also includes kittens, small terminal programs that extend kitty with additional functionality.
