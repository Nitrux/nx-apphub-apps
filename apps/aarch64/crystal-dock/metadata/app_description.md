# Crystal Dock

## Summary

A cross-desktop Wayland dock

## Description

Crystal Dock is a desktop panel for Wayland desktops, with a polished interface and support for Hyprland, KDE Plasma 6, Labwc, LXQt, Niri, and Wayfire.
